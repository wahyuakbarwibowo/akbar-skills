akbar-skills

Two portable agent skills, one SKILL.md each, installable into four agents.

codebase-map

Read an existing codebase, write docs/CODEBASE_MAP.md — a durable artifact other agents load instead of re-exploring.

lean-code

Write the smallest correct change: reuse → stdlib → native → one line.

Install

Any agent

npx akbar-skills          # all four, no clone
npx akbar-skills claude   # or codex | opencode | kilocode

Claude Code, as a plugin

/plugin marketplace add wahyuakbarwibowo/akbar-skills
/plugin install akbar-skills@akbar-skills

From a clone

git clone https://github.com/wahyuakbarwibowo/akbar-skills
cd akbar-skills && ./install.sh

Where the files land

AgentPathInvoke
Claude Code~/.claude/skills/<name>/SKILL.mdauto (matched on description) or /<name>
Codex~/.codex/prompts/<name>.md/<name>
opencode~/.config/opencode/skill/<name>/SKILL.mdskill tool / by description
Kilo Code<project>/.kilocode/workflows/<name>.md/<name> — per project, run from repo root

Global installs except Kilo Code, which is per-project. Edit skills/<name>/SKILL.md and re-run the installer to update everywhere.

The artifact

codebase-map writes docs/CODEBASE_MAP.md into the target repo — plain markdown, every claim citing a path, stamped with the commit sha. Any agent reads it directly; commit it so the next session starts warm.
